# Documentação do EcoScan

Esta pasta reúne a documentação técnica e o acompanhamento do projeto EcoScan.

## Documentos

| Documento | Descrição |
|---|---|
| [ARQUITETURA.md](ARQUITETURA.md) | Organização dos serviços e comunicação entre componentes |
| [API.md](API.md) | Endpoints, autenticação e exemplos de utilização |
| [STATUS.md](STATUS.md) | Situação atual das funcionalidades e integrações |

## Organização

A documentação está dividida em três partes:

- Arquitetura: explica como os componentes do sistema estão organizados.
- APIs: descreve as rotas e os contratos conhecidos.
- Status: acompanha o que já foi implementado, testado e o que ainda precisa ser validado.

Os arquivos README.md dentro de cada serviço backend apresentam instruções específicas de configuração e execução.

## Atualização

O arquivo `STATUS.md` é a referência oficial para consultar o andamento atual do projeto.

O arquivo `STATUS_DESENVOLVIMENTO.md` deve ser considerado um registro de acompanhamento anterior, não substituindo o status oficial.
